# Business Card

A personal business card built with pure HTML and CSS.

The project was created as part of my front-end learning journey, with a focus on building a modern, responsive and visually polished interface from scratch.

## About the project

This business card presents my professional profile, role, location and links to my main professional channels.

The interface was designed with a modern and technology-oriented visual style, using dark colors, gradients, responsive layouts and interactive states.

## Technologies

- HTML5
- CSS3
- Flexbox
- Responsive Design
- Media Queries

## What I practiced

During this project, I practiced:

- Semantic HTML structure
- CSS selectors and classes
- Box model
- Flexbox
- Spacing with margin, padding and gap
- Responsive layouts
- Hover and focus states
- Gradients and shadows
- Basic accessibility
- GitHub Pages deployment
